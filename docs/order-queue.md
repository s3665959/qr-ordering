# Order queue flow

คิวออเดอร์ปกติใช้สถานะดังนี้:

```text
NEW (รอรับออเดอร์) → ACCEPTED (รับออเดอร์แล้ว) → SERVED (เสิร์ฟแล้ว)
```

- พนักงานกด `รับออเดอร์` เพื่อเปลี่ยน `NEW` เป็น `ACCEPTED`
- พนักงานกด `เสิร์ฟแล้ว` เพื่อเปลี่ยน `ACCEPTED` เป็น `SERVED`
- `SERVED` เป็นสถานะปลายทาง และไม่มีปุ่มเปลี่ยนสถานะต่อ
- การยกเลิกและ permission เดิมยังคงใช้ผ่าน transition validation เดิม
- API ไม่รับคำขอสร้างหรือเปลี่ยนงานใหม่ไป `PREPARING` หรือ `DELIVERING`

## รองรับออเดอร์เก่า

ยังคง enum, status event และข้อมูลในฐานข้อมูลของ `PREPARING` และ `DELIVERING` ไว้ ไม่ migrate ย้อนหลังหรือลบประวัติ ออเดอร์เก่าสองสถานะนี้ยังแสดงในคิวตามสถานะจริง และมีปุ่ม `เสิร์ฟแล้ว` เพื่อจบงานเป็น `SERVED` โดยไม่สร้างสถานะเก่าเพิ่มใน flow ใหม่

transition ที่อนุญาตคือ `NEW → ACCEPTED`, `ACCEPTED → SERVED`, `PREPARING → SERVED`, `DELIVERING → SERVED` และการยกเลิกตามสิทธิ์เดิม การอัปเดตสถานะใช้เงื่อนไขสถานะเดิมในคำสั่ง update เพื่อให้คำขอที่กดซ้ำหรือชนกันสำเร็จได้เพียงคำขอเดียว ส่วนหน้าลูกค้ายังคง polling ทุก 5 วินาทีและแสดง label ภาษาไทยชุดเดียวกับหน้าพนักงาน

## วันทำการและประวัติ

- วันทำการใช้เวลา `Asia/Bangkok` และเริ่มใหม่ทุกวันเวลา 04:00 โดยคำนวณช่วง `[04:00, 04:00)` จากเวลาจริงของฐานข้อมูล ไม่ต้องมี job และไม่เปลี่ยน timestamp เดิม
- ออเดอร์ที่ยังไม่ใช่ `SERVED` หรือ `CANCELLED` ไม่ถูกกรองตามวันทำการ จึงคงอยู่ในคิวข้ามวันได้
- คอลัมน์ `เสิร์ฟแล้ว` แสดง 10 รายการล่าสุดของวันทำการปัจจุบันตาม `servedAt` และแสดงจำนวนรวมทั้งหมดของวันนั้น
- `/orders/history` กรองวันทำการ โต๊ะ และสถานะ พร้อมแบ่งหน้า โดยใช้ `servedAt` สำหรับ `SERVED`, `cancelledAt` สำหรับ `CANCELLED` และ `orderedAt` เฉพาะงานที่ยังไม่จบ; ข้อมูลเก่าที่ไม่มี timestamp จบงานยังแสดงย้อนหลังได้โดยเป็น `NULL` และแสดง “ไม่ระบุเวลา” ห้ามอนุมานเวลา
- โหมด `unknownCompletionTime=1` ใน URL แสดงเฉพาะ `SERVED` ที่ `servedAt IS NULL` หรือ `CANCELLED` ที่ `cancelledAt IS NULL` โดยไม่กรองวันทำการ แต่ยังกรองโต๊ะ/สถานะและแบ่งหน้าได้; โหมดปกติไม่นับข้อมูลกลุ่มนี้
- การ์ดเสิร์ฟแล้วในคิวแสดงโต๊ะกับเวลาเป็นค่าเริ่มต้น กด `Expand` เพื่อดูเลขออเดอร์และรายการอาหาร; state การเปิดการ์ดอยู่ใน client จึงไม่ถูก polling ยุบ
